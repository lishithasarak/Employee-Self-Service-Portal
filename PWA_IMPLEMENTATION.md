### 3. **Service Worker** (`sw.js`)
Generated automatically by Workbox with intelligent caching strategies:

| Resource Type | Strategy | TTL | Max Size |
|---|---|---|---|
| HTTPS resources | Network-First | 7 days | 200 entries |
| API calls (`/api/*`) | Network-First (5s timeout) | 5 minutes | 100 entries |
| Uploads (`/uploads/*`) | Cache-First | 30 days | 50 entries |

**Benefits:**
- Offline functionality for cached data
- Reduced bandwidth consumption
- Faster app load times
- Smart fallback to cache when offline

## Caching Behavior

### First Load (Online)
1. Download all static assets
2. Establish service worker
3. Cache manifest resources
4. Store API responses

### Repeat Loads (Online)
1. Serve static files from cache (instant)
2. Check for API updates (network-first)
3. Show cached data while fetching updates
4. Display fresh data when ready

### Offline Access
1. Service worker intercepts requests
2. Return cached resources
3. Show appropriate offline indicators
4. Queue actions for sync when online

## Rollback Instructions

If PWA needs to be disabled:

1. Remove PWA plugin from `vite.config.js`:
   ```javascript
   // Remove VitePWA import and plugin
   ```

2. Remove PWA meta tags from `index.html`

3. Remove service worker registration from `main.jsx`

4. Delete `/public` folder

5. Run `npm run build` to rebuild without PWA
